# Aholo 3D 作品原型 · 合作预览

在线试玩：<https://siuserxiaowei.github.io/aholo-case-preview/>

- [月亮迟到了](https://siuserxiaowei.github.io/aholo-case-preview/moon/)：空间解谜，约 3–5 分钟。
- [将进酒 · 醉界](https://siuserxiaowei.github.io/aholo-case-preview/jinjiu/)：沉浸演出，约 60–90 秒。
- [妖王 · 重制版](https://siuserxiaowei.github.io/aholo-case-preview/yaowang/)：西游风格动作游戏，迎战石甲妖王。

建议使用电脑体验。首次访问需要加载 3D 模型：诗词作品约 40 MB，妖王约 27 MB。

## 来源与署名

此仓库保存原合作预览站的静态发布文件，来自原站版本 2（源码快照 `6d7d30be9f3dd6400e8f5f1532c614f922af7777`）。仅调整网页和模型的资源路径，以便在 GitHub Pages 子目录下运行。

作品开发分支保留在原作者与贡献者所属的私有仓库中，访问需要仓库权限：

- [hyai-dev/aholo3d-hackathon · moon-late](https://github.com/hyai-dev/aholo3d-hackathon/tree/moon-late/demos/moon-late)
- [hyai-dev/aholo3d-hackathon · jinjiu](https://github.com/hyai-dev/aholo3d-hackathon/tree/jinjiu/demos/jinjiu)
- [hyai-dev/aholo3d-hackathon · demo/yaowang-v2](https://github.com/hyai-dev/aholo3d-hackathon/tree/demo/yaowang-v2/demos/yaowang-v2)
